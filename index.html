Tentang Proyek UAS MoneyMind

Aplikasi ini dirancang sebagai proyek akhir semester (UAS) mata kuliah Pemrograman Web / Sistem Informasi. Dibangun menggunakan arsitektur Vanilla JavaScript murni, CSS responsif, dan LocalStorage client-side sehingga 100% siap di-deploy langsung pada GitHub Pages.
